# Learning log

One line per concept, the date, and the file where it was first used.
When a concept comes back, reread the note rather than asking for it again.

| Date | Concept | First used in |
|---|---|---|
| 2026-10-03 | **Design tokens.** Named variables hold every visual value, and components reference the name rather than the value. Change `--surface-1` once and every card follows. The discipline is that a component must never contain a raw hex, pixel size, radius or duration, because the moment one does, that component stops following the system and nobody notices until a recolour misses it. | `assets/components.css`, values from `tokens.css` |
| 2026-10-03 | **Why training content has to be structured data.** Two live examples found on the same day. The exercise prescription is a single string, `"Build to 30 seconds"`, so the card cannot render set rows: there is nothing to count. And `CURRENT = 2` in `weeks/index.html` is a hand set constant with no course start date behind it, so it silently went stale and nothing in the repo could detect it. Both are the same bug: a fact about training that exists only as display text cannot be reasoned over. | `assets/week.js`, `weeks/index.html` |
| 2026-10-03 | **Cascade order decides which token system wins.** `tokens.css` and `assets/styles.css` both define `--bg`. Loading tokens second makes the page near black while every variable the two files do not share, like `--panel` and `--line`, still resolves from the old file. That is why importing tokens moved the page background but left the block cards navy. | `weeks/week-2.html` |
| 2026-10-03 | **Parse authored text into structure once, in the data layer.** A coach writes "3 sets of 8" and "Build to 30 seconds" as sentences, because that is how a prescription is written. Workout mode needs sets, a target and whether the set is timed. `parseDose` turns the sentence into those fields once, so every component reads structure and no component ever re-reads the sentence. The rule that makes it safe: a sentence it cannot read becomes an open set carrying the coach's original words, never a guessed number, because a guessed number is a wrong instruction to somebody training. | `assets/engine.js`, consumed by `assets/screen-session.js` |
| 2026-10-03 | **A design system owns its own reset.** The new screens looked correct only because `assets/styles.css` happened to set `box-sizing: border-box` globally. Migrated pages stopped loading that file, and nothing had ever reset the body's default 8px margin, so every new screen sat 8px off centre and overflowed by 8px. "It looked fine" meant another stylesheet was in the room. | `assets/components.css` |
| 2026-10-03 | **A green build is not a served site.** `git commit --amend`, run only to reword a message, replaced a 49 file commit with an empty tree. Every file stayed on disk so nothing looked wrong locally, GitHub Pages built the empty commit, reported success because an empty site builds fine, and served 404 for the entire site. The check that finds it in one second is `git ls-tree -r --name-only HEAD \| wc -l`. The check that catches it from outside is to curl a path that existed *before* the change: if an old path 404s too, suspect the commit, not the host. | `git`, GitHub Pages |
